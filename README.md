# Cosmic Explorer

An interactive 3D space website. Drag to look around, pinch to zoom, and fly between Earth, the Moon, Mars and Jupiter.

Built with Vite, vanilla JavaScript and Three.js. No backend, database, API key or login. Every planet, star and nebula is generated by code, so there are no image files to break.

**What you can do**

- Drag with one finger (or the mouse) to rotate the view. Pinch (or scroll the mouse wheel) to zoom.
- **Reset** returns to the default view. **Pause / Play** freezes or resumes the motion. **Stars** shows or hides the stars.
- Tap **Earth, Moon, Mars or Jupiter** to fly there. Each one shows a short description and a "Science and art" note that separates accurate facts from artistic decoration. **Back to Earth** appears when you are elsewhere.

## Put it online from an Android phone

You only need a phone with Chrome and a free GitHub account. Do the steps in this order.

### 1. Get the files ready

1. Download `cosmic-explorer.zip`.
2. Open the **Files by Google** app, find the zip in Downloads, tap it and choose **Extract**. You now have a folder called `cosmic-explorer`.

### 2. Create the repository

1. Open [github.com](https://github.com) in Chrome and sign in (or sign up).
2. Tap the **+** at the top and choose **New repository**.
3. Name it anything you like, for example `cosmic-explorer`. Keep it **Public**, then tap **Create repository**.

### 3. Turn on GitHub Pages first

Doing this before uploading means the first deployment works straight away.

1. In your repository, tap **Settings**. If you cannot see it, tap the **⋮** menu in Chrome and turn on **Desktop site**.
2. Tap **Pages** in the left menu.
3. Under **Build and deployment**, set **Source** to **GitHub Actions**.

### 4. Upload the main files

1. Go back to the repository's main page (the **Code** tab).
2. Tap **Add file**, then **Upload files**.
3. Tap **choose your files**, open the extracted `cosmic-explorer` folder, and select these files (tap and hold the first one, then tap the others):
   - `package.json`
   - `vite.config.js`
   - `index.html`
   - `README.md`
4. Tap **Commit changes**.

### 5. Add the `src` folder

GitHub cannot create an empty folder, so make it with a first file:

1. Tap **Add file**, then **Create new file**.
2. In the name box type `src/placeholder.txt` (typing the `/` creates the folder). Type any text in the body, then tap **Commit changes**.
3. Open the new `src` folder, tap **Add file**, then **Upload files**.
4. Choose all nine files inside the extracted `src` folder: `main.js`, `style.css`, `textures.js`, `planets.js`, `galaxy.js`, `starfield.js`, `controls.js`, `ui.js` and `data.js`. Tap **Commit changes**.
5. Optional tidy-up: open `src/placeholder.txt` and delete it.

### 6. Add the two hidden files

Phone file pickers often hide files whose names start with a dot, so create these in GitHub's editor instead. For each one: **Add file → Create new file**, type the name exactly, paste the text, then **Commit changes**.

**File name: `.gitignore`**

```
node_modules/
dist/
*.log
.DS_Store
.env
.vite/
```

**File name: `.github/workflows/deploy.yml`** (add this one last, because it starts the deployment)

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [main, master]
  workflow_dispatch:

permissions:
  contents: read
  pages: write
  id-token: write

concurrency:
  group: pages
  cancel-in-progress: false

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - uses: actions/setup-node@v6
        with:
          node-version: 22
      - run: npm install --no-audit --no-fund
      - run: npm run build
      - uses: actions/configure-pages@v5
      - uses: actions/upload-pages-artifact@v5
        with:
          path: dist

  deploy:
    needs: build
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - id: deployment
        uses: actions/deploy-pages@v5
```

### 7. Watch it deploy and open your site

1. Tap the **Actions** tab. A run called **Deploy to GitHub Pages** starts. It takes about one to two minutes. A green tick means success.
2. Your site is at `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY-NAME/`. You can also find the link under **Settings → Pages**, or in the **deploy** step of the finished run.
3. Open it in Chrome on your phone. The first screen may look soft for a second or two while sharper textures finish generating, shown by a thin blue line at the top.

If a run fails with a red cross, tap it, read the red message, and see Troubleshooting below. You can run it again with **Re-run all jobs**.

## The base path (why the site works from any repository name)

A project site lives at `https://USER.github.io/REPOSITORY/`, not at the root. `vite.config.js` sets `base: './'`, which makes every file path in the built site relative, so it loads correctly from that URL **without** hardcoding your username or repository name. You do not need to change anything.

If you ever need an absolute path instead (for example behind a custom setup), build with an environment variable:

```
VITE_BASE_PATH=/your-repository-name/ npm run build
```

## Run it on a computer (optional)

Requires Node.js 18 or newer.

```
npm install
npm run dev       # opens a local preview with live reload
npm run build     # creates the production site in dist/
npm run preview   # serves the built site locally
```

`npm run dev` and `npm run preview` also print a network address, so you can open the site on your phone while on the same Wi-Fi.

## Project layout

| File | What it does |
| --- | --- |
| `index.html` | Page structure: canvas, buttons, info card, planet selector |
| `src/main.js` | Starts everything, runs the animation loop, handles resizing and cleanup |
| `src/textures.js` | Generates all planet surfaces, the nebula and sprites with code |
| `src/planets.js` | Earth (day/night shader, clouds, atmosphere), Moon, Mars, Jupiter |
| `src/galaxy.js` | A spiral galaxy you can fly to |
| `src/starfield.js` | Thousands of stars, nebula backdrop, distant Sun and galaxies |
| `src/controls.js` | Touch and mouse camera: drag, pinch, momentum, fly-to |
| `src/ui.js` | Connects the on-screen buttons and info card |
| `src/data.js` | Descriptions, facts and science-versus-art notes |
| `src/style.css` | Layout and look of the interface |
| `.github/workflows/deploy.yml` | Builds and deploys to GitHub Pages |

## How it stays fast on phones

- Pixel ratio is capped at 2, and quietly lowered if frames run slow.
- Stars are one draw call (a single `Points` object), not thousands of meshes.
- No post-processing. Soft glows are simple additive shaders.
- Textures are generated in short slices across frames, starting low-resolution so the scene appears quickly, then sharpened in the background.
- Rendering stops while the tab is hidden, and while paused and idle.
- GPU resources are released when the page closes, and the app recovers if the browser reclaims the graphics context.
- If WebGL is unavailable, a friendly message is shown instead of a blank page.

## Science and art

The sizes of Earth, the Moon, Mars and Jupiter are to scale with each other, and the Moon is tidally locked. Everything else is artistic: continents, clouds, city lights, craters, Mars and Jupiter surface patterns, the nebula and the distant galaxies are procedural. Distances are heavily compressed. The info card for each world repeats this in one line.

## Troubleshooting

- **Page shows 404:** Settings → Pages → Source must be **GitHub Actions**. Then Actions → latest run → **Re-run all jobs**.
- **Run fails at "Install dependencies":** check `package.json` was uploaded exactly and is not empty.
- **Run fails at "Build the site":** open the run and read the red lines. A missing file in `src/` is the usual cause. Check that all nine files are there.
- **No Actions run appeared:** make sure `.github/workflows/deploy.yml` exists on the `main` branch, then use **Actions → Deploy to GitHub Pages → Run workflow**.
- **Blank black screen with a message:** your browser has WebGL turned off. Update Chrome or try another browser.
- **Choppy on an older phone:** the app lowers its resolution automatically after a few seconds. Closing other apps helps.
